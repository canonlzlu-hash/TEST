# 打工人小账本

一个真正使用在线数据库的个人工作台，用来计算真实时薪、快速记账、跟踪自由基金，并模拟通勤、加班和涨薪对时薪的影响。

## 功能

- 真实时薪计算：综合到手月薪、发薪月数、工作成本、在场时间、通勤和加班
- 10 秒记账：收入、固定支出、弹性支出，保存后换算为工作时间
- 在线流水：新增、修改、删除即时写回 Cloudflare D1
- 月度收支、自由基金、安全垫和 SVG 存款曲线
- 通勤、加班、涨薪情景模拟
- 桌面侧栏与手机底部 Tab 响应式布局
- 加载、错误提示和重试状态

## 本地运行

```bash
pnpm install
pnpm dev
```

项目使用 Vinext、React、TypeScript、Drizzle ORM 和 Cloudflare D1。部署到 ChatGPT Sites 时，`.openai/hosting.json` 中的 `DB` 绑定会连接线上数据库。

> 仓库只包含代码和数据库结构，不包含任何真实流水或个人设置数据。
